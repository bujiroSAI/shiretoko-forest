こぶしの森設立趣意書

いまから、“野生”を編み直そう。

人と森が切り離されてしまった。土の匂いで天気を読み、葉の揺れで獣の気配を察し、食べられるものと食べられないものを身体で判断する。——かつて確かに存在していた感覚や霊性を、現代の人間はもはや持たない。森は管理されるものになり、自然は鑑賞されるものになった。私たちは、その「野生」を編み直すことに挑戦したい。それは快適さや安心を提供する体験ではなく、獣の気配に怯え、名前もわからない植物を口にし、暗い森に一人で踏み込む緊張を伴うようなものだ。ときに不快でおどろおどろしく、しかし確かに身体が啓かれていくだろう。そうした時間の中にこそ、現代の生活が静かに奪い続けてきたものが眠っていると信じている。世界には、整えられた美しさや保証された快適さでは届かない体験がある。今私たちが求めているのは、消費される体験ではなく、自分の中に刻まれるものだ。私たちが知床で作るのは、森を媒介にした一つの器だ。嘘偽りのない自然を土台に、食・文化・芸術といったあらゆる営みが乗ることのできる、新しい森。北方文化圏の入り口に位置するこの地から、その器を通じて、新しい自然体験を世界へ発信することを目指す。いまから、“野生”を編み直そう。

Reference 01 ∕ Tono

遠野 — 物語を核に、
人と資本が集まり続ける町。

柳田國男『遠野物語』の町（人口約2.4万人）。この10年、外部からクリエイターと資本が集まり続けている。何が起きていて、誰がやっていて、どういう仕組みなのか。

何が起きているか

二枚看板——ホップ×ビール（産業）と、遠野物語×郷土芸能（文化）。移住者が醸造所やプロデュース会社を起こし、道の駅は年80万人・全国5位。

アーティストは観客ではなく「踊り手」として参加する。コムアイはしし踊りを稽古して奉納し、2025年にはK-BALLET×横尾忠則の『踊る。遠野物語』が全国巡演へ。

誰がやっているか

富川岳（元広告会社→2016年29歳で移住）。文化事業「to know」を営み、自らしし踊りの踊り手となり、市の文化機関の運営委員も務める——外部人材が土地の文化の内側に入った例。

入口はNext Commons Lab（2016年・全国第1号拠点）。10テーマの公募に約500件の応募、15名が移住。醸造・デザイン・プロデュースの担い手になった。

どういう仕組みか

三層構造。需要を保証する企業（キリン: 1963年からホップ全量買取・1.5億円出資）が上にいて、市が協力隊とふるさと納税で人と金の入口を作り、民間法人群が実装する。

「作れば売れる」状態が先にあるから、高リスクの挑戦に人が入れる。

知床への翻訳: 北こぶしリゾートが「キリン」の位置に立つ。
ホテルという確実な需要（宿泊者・レストラン・バー）が、フォレジング・アート・ガイドの供給側リスクを吸収する。遠野は物語でそれをやった。知床は身体でやる。

知床の絵を、ひとつの様式では描かない。理由は土地の履歴にある——ここは何度も境界が引かれ、混ざり、塗り替えられてきた場所だから。

オホーツク文化

海獣狩猟民の文化。クマ儀礼の源流。リゾートの足元の遺跡から出土する。

アイヌ文化

この半島の名の由来（sir etok＝大地の突端）。人と獣が対等に向き合う世界観。

1917–

本州からの入植

測量の線、畑、人工林。桑島家3世代の歴史はここに連なる。

Now

自然と人間

いま引かれている境界。この森づくり自体が、その最前線にある。

方針: どれか一つを選ばない。境界に堆積してきた要素をハイブリッドし、体験設計が引き立つ「パーク」全体のイラストとして統合する。

絵の考え方 — 決め方を3つに分ける

考え方 1 ∕ 視点 — 俯瞰か、断面か

俯瞰で描く。

比較
断面は、植生のゾーニングや森が育つ時間軸を示しやすい。俯瞰は、体験設計の全体をひと目で感じさせる。
方針
この絵のゴールは見た人がワクワクし、土地に関わりたくなること。だから俯瞰。
補足
精緻な俯瞰図は高野ランドスケープが別途作成予定。この絵はあくまでコンセプトを説明するための図。
考え方 2 ∕ 距離と角度

やや引きで、少し角度をつけて、立体感を出す。

幅
距離は「知床全体を包む」から「エリアの中にフォーカス」まで。角度は「真上」から「傾斜をつけた鳥瞰」まで。
方針
現時点ではやや引きのイラストに、少し角度をつけて立体感を感じさせるのが良いと考えている。最終はデザイナーと詰めるので、任せてほしい。
考え方 3 ∕ トーン

少しのリアルさに、土地のデザインコンテクストをオマージュとして重ねる。

方針
下の4方向を事例の土台に、デザイナーと詰めていく。ややリアルな描写をベースに、ランドスケープの森のデザイン、入植時代のレトロデザイン、アイヌの雲などの意匠モチーフ、クマと祭壇などオホーツクの世界を織り込み、全体は大和絵のような世界観で統合する（対外的に最も求心力がある）。

05 ∕ Forest Implementation
森 の 実 装 に つ い て

森づくりの論点は、6つ。

順番に意味がある——まず安全（柵）、つぎに木、それから道と人。アートと建築はこの土台の上に載せる。

#テーマ論点方針
1柵設けるか安全管理上、必須（今日決めたい）
2範囲どこまで囲うか約1ha〜全域8haの間で、一緒に決める
3更新皆伐か間伐か柵の内外で分ける。少しずつ・100年単位
4植栽天然林かトドマツか天然林は柵内のみ成立。内=天然林・外=トドマツ
5道体験と管理の兼用作業道2.5mを基盤に、核心部のみ分離
6施業と材誰と伐り、材をどうするか組合以外の長期パートナー探し。材はホテルで使う
論点 1 ∕ 柵 — 今日決めたい

コンセプト上は不要。安全管理上は、絶対に必要。

論点
柵を設けるか。
事実
シカは植えた木を食べ尽くす。ヒグマとの距離は運まかせにできない。
方針
設ける。コンセプトで柵を正当化しない——安全の土台として率直に。種類は電気柵・熊柵仕様（羅臼で冬季運用の実績あり）。ゲート管理と草刈りが継続することも込みで。
論点 2 ∕ 範囲 — 一緒に決めたい

小さく囲えば安いが窮屈。大きく囲えば自由だが高い。

案範囲特徴
ミニマム散歩道まわり（約1ha）最も安い。「囲われてる感」は出る
中間人の森ぜんぶゾーン設計と整合
マックス敷地全域（約8ha）森の再生まで守れる。最も高い
方針
広く囲うほど天然林に戻せる面積が増える——範囲は費用と植栽の野心のバランス。概算延長・費用を図面と共に提示し、一緒に決める。
論点 3 ∕ 更新 — 考え方を共有したい

「間伐でゆっくり育てる」は、全域には使えないとわかった。

事実
長年間伐されず高密度化した林は、いま間引くと風の通り道ができ、残った木が倒れるおそれ（森林組合の見解）。
方針
柵の内外で分ける。内側は手を入れず残す（危険木処理のみ）。外側は道沿いから少しずつ皆伐→植え替え。原則は「①道をつける ②少しずつやる ③100年で考える」（高野ランドスケープ）。
論点 4 ∕ 植栽 — 考え方を共有したい

本当は天然の森に戻したい。でも、シカがいる。

事実
隣の100平方メートル運動地では、植えた広葉樹をシカがほぼ全滅させた。残ったのはシカが食べない木だけの単調な林——40年経っても本物の森の複雑さは戻っていない。
方針
広葉樹は柵の内側でしか育たない。柵内＝天然林化（ミズナラ×トドマツの本来の植生へ）、柵外＝トドマツ再植林、の分担を軸に。
論点 5 ∕ 道 — 現地で見たい

森の手入れは、道から始まる。

論点
体験の道と管理の道を兼ねるか、分けるか。
方針
幅2.5mの作業道を基盤に、体験の核心部だけ分離。柵の線と一緒に図面化し、現地で重なりを確認する。
論点 6 ∕ 施業と材 — 方針を共有

「少しずつ」は組合の商売に合わない。伐った木は、ホテルで使う。

事実
森林組合は補助金＋大型機械の皆伐が前提。少しずつ進める方式は受けてもらえない可能性が高い。
方針
長い目で森を育てる組合以外のパートナー（北見方面など）を探す。伐ったトドマツはラウンジの建材・家具やクラフト・薪へ——伐ることが体験と経営に還る回路を作る。

お金のものさし

基準線は、いま入っている森林組合の助成（補助金で皆伐して植え直す＝最も軽いが、森の姿は選べない）。そこからどれだけ離れて、どんな森を手に入れるか——が費用の議論の全体。

Layer Aどのみち、かかるお金
森を持っているだけでかかる費用。人工林の更新・危険木処理・シカ対策。
Layer Bこの計画ならでは、のお金
柵（範囲しだい）・道・植栽・ランドマーク・ラウンジ建築。
Layer Cずっと続くお金
草刈り・ゲート管理・冬支度・ガイド・仕込み。ここを続けられるかが勝負。
着手順やること備考
第1段柵＋道＋最初の植栽・入れ替え着手森の都合で先送りできない
第2段ランドマーク＋アート＋散歩道の仕上げ建築なしでも体験は成立
第3段ラウンジ建築伐った木で建てる

回収は森単体ではなく、宿泊単価・ブランド価値・連泊で見る（滞在型観光への転換と同じ線上）。

A. シレトコ＝「地の果て」ではなく「大地の突端」

アイヌ語 sir-etok。「終わり」ではなく「大地が海へ差し出した先端」。ウトロ＝ウトゥルチクㇱ「その間を・我々が・通る・所」——巨岩の間の水路を舟で抜けて入る集落だった。
